# XIAOYUE 创意系统

建立一份持续生长的索引，收录做过、测试过和学到的事物。它的北极星是 `柔软档案 × 好玩交互 × Apple 级精致度 × 严肃 AI 作品`。不要用当前职位、单一视觉风格或冷峻的编辑式作品集来定义 XIAOYUE。

## 从证据出发

为现有体验提出艺术方向之前，先检查真实仓库、渲染页面、当前内容和用户提供的每张图片。不要只从 CSS 推断审美。如果项目中存在 `VISUAL_AUDIT.md`、`CREATIVE_SYSTEM.md` 或 `references/REFERENCE_LIBRARY.md`，应读取相关文件，并保留其中较新的项目专属决策。

处理 XIAOYUE 的网站结构、世界分流、路由或分阶段实施时，还要读取[信息架构](references/information-architecture.md)。

进行新的审计或建立新的参考集合时，读取[审计协议](references/audit-protocol.md)。选择或组合参考时，还要读取[参考资料库](references/reference-library.md)。用户要求“差异化”“不像模板”或“更像本人”时，必须执行审计协议中的差异化测试，而不是只换色、换字体或增加装饰。

## 选择所属世界

- **ARCHIVE** 用于个人身份、笔记、花园、阅读、速写、学习和个人实验。它温暖、有触感、曲线柔和、好玩、私人，并以物件为中心。
- **WORK** 用于产品、系统、Agent、生成式媒体、演示和案例研究。它从 Archive 展开，成为精致、由媒体主导、针对具体项目的能力证据。
- **LAB** 用于模型、算法、训练、评估、Benchmark、复现和研究。它是一张可追溯的实验桌，而不是黑白学术海报。

每个页面或章节只选一个主要世界。转场可以跨越世界，但不要把三者平均混成同一种绿色卡片风格。共享身份锚点、字体、颜色、间距、构图、证据状态和质量门槛见[完整创意系统](references/creative-system.md)。

## 始终保留同一个人的辨识度

稳定身份来自中文主叙事、真实性边界、个人成长痕迹、内容与物件的对应关系，以及跨世界的连续体验。档案编号、Bloom、索引脊线、绿色、Mono、手写字、纸张和受控叠层是可选择的表达素材，不是必须同时出现的品牌套装。每个页面只选能解释其内容的少量锚点；即使移除名字，仍应能从内容选择与行为认出 XIAOYUE。

在生产环境实现字标时，复用[品牌资产说明](assets/brand/README.md)及其附带的官方 Kaushan Script WOFF2/OFL 文件。保留弯引号；该字体仅用于英文字标；不得声称 Chloe 拥有此字体。

把圆角叠纸、拖拽、点击打开、层级遮挡和柔和落桌视为 Archive 的标志性交互。不要用说明文字、静态网格或显眼的重置控件取代这套行为。

## 差异化门槛

不要把 XIAOYUE 定义成“复古档案风网站”。可拖动桌面、Digital Garden、纸张拼贴、Mono 编号、植物和手写字都已是常见表达，单独使用不构成差异。

差异化公式是：`个人痕迹 × 物件语义 × 真实证据 × 世界反差`。

- **个人痕迹**：保留早期笔记、失败实验、真实近况和用户明确选择，不制造完美但匿名的作品集人格。
- **物件语义**：物件的形状、材料、动作和目的地必须由内容决定；项目替换后不能只换标题继续成立。
- **真实证据**：柔软物理外壳打开后必须通向可试用产品、真实界面、运行结果、代码、论文或明确边界。
- **世界反差**：Archive 亲密好玩，Work 聚焦产品，Lab 严谨可追溯；技术实力由打开后的证据证明。

访客可见的入口、按钮、状态说明和操作提示默认使用自然中文。英文只保留不可替代的技术名词、正式产品名或极轻的 metadata；禁止用 `OPEN FILE`、`INSPECT`、`EXPLORE` 等装饰性英文代替“打开演示”“查看实验”“阅读笔记”。

每屏最多突出一个材料主角和一个标志性行为。不要用更多光标特效、贴纸、纹理或动效补救缺乏内容专属性。`Apple 级精致度` 只指完成度、状态连续性、性能、可访问性和视觉校准，不指复制 Apple 的白底、字体、摄影或滚动模板。

`XIAOYUE` 是整套数字空间与作品身份；`Chloe’s Archive` 是 Archive 世界的正式英文字标。不要把两者同时当作重复口号。

## 让主体成为主角

为每个视口确定唯一主角：人、产品、系统、实验或某份证据。持续减少周围文案和装饰，直到主角一眼可辨。

## 必须使用真实媒体与真实证据

- 不要用图库照片、装饰渐变、通用样机或虚构 UI 填补关键媒体缺口。
- 缺少真实素材就无法完成设计时，发出 `MEDIA REQUEST`，写明类型、用途、位置、宽高比、尺寸、必要参考、建议采集或生成方式以及验收标准。
- 所有声明必须归类为 `VERIFIED`、`REPOSITORY REPORTED`、`PROTOTYPE` 或 `WIP`。
- 绝不能把仓库已有报告中的指标说成本次任务实际跑出的结果。

## 与专项 Skills 协作

- 布局、字体、颜色、组件和响应式行为使用 `xiaoyue-ui-director`。
- 转场、滚动编排和交互使用 `xiaoyue-motion-director`。
- 可能需要动态媒体时使用 `xiaoyue-video-director`。
- 以证据为核心的案例研究使用 `xiaoyue-portfolio-director`。

不要自动调用所有专项 Skill；只把当前任务真正需要的部分分发出去。
