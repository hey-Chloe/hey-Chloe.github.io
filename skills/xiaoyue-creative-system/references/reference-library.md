# XIAOYUE 参考资料库

版本：0.3 / 2026-09-07

这不是一份情绪板（moodboard）清单。每条参考都记录使用场景、可吸收原则、禁止复制内容、证据状态和未来素材需求。

## 使用分流

- 设计 Archive 时优先读参考 01、02、03。
- 设计 Work 时优先读参考 03、04、05。
- 设计 Lab 时优先读参考 03、05、06。
- 需要视频时不要直接复制本文件中的描述；调用 `xiaoyue-video-director` 先完成媒介判断与制作简报（Production Brief）。

## 参考 01 — GitHub 绽放身份

文件：[`../assets/reference-01-github-profile.png`](../assets/reference-01-github-profile.png)  
证据：用户上传原图，2010 × 1652。  
用途：GitHub 个人主页、Bloom 身份和友好的技术分类。

### 吸收

- 温暖的珊瑚色 / 桃色 / 鼠尾草绿色板；
- 以“绽放”隐喻持续学习与成长；
- 花瓣、太阳、天气等小型趣味细节；
- Field Guide（野外指南）式分类法；
- 大留白与标签密度的对比。

### 不复制

- 精确花朵 SVG；
- 完整技术标签墙；
- 纯居中页面；
- 依赖第三方服务的统计图片；
- 把当前技术栈固定成长期职业定义。

### 可转译组件

- `BloomMark`
- `FieldGuideIndex`
- `SeasonalState`
- `EvidenceChip`（只用于证据状态，不用于技能熟练度）

## 参考 02 — Archive 世界

文件：[`../assets/reference-02-archive-world.png`](../assets/reference-02-archive-world.png)  
证据：用户上传原图，3298 × 2201。  
用途：Archive 身份、首页世界入口、材料与叠层。

### 吸收

- 低饱和苔绿色、近黑桌面、暖色纸张构成的材料三角；
- 稳定设备 / 桌面容器与不规则纸张的对照；
- `Chloe’s Archive` 手写字标 + Mono 标签 + 中文 Sans；Serif 只在少数时刻使用；
- 高密度中心与大面积安静空间；
- 圆角大框、圆角纸片、柔和苔绿色与手工叠放；
- 叠纸 + 拖动 + 点击 + 遮挡构成玩法本身，是必须保留的标志性交互（Signature Interaction）。

### 不复制

- 精确的笔记本电脑外框；
- 相同纸张坐标、尺寸与 logo；
- 每一页都延续同一雾绿背景；
- 用半透明卡片替代真实内容；
- 大量手写体文本。
- 把叠纸变成带长篇教程和显眼重置按钮的工具界面。

### 可转译组件

- `ArchiveDesk`
- `ObjectDrawer`
- `PhotoSleeve`
- `IndexTab`
- `WorldPortal`

## 参考 03 — 当前仓库行为

来源：`hey-Chloe.github.io` 源码和线上运行。  
检查快照：2026-09-07，commit `2c48163`；使用前应重新核对，不把此条永久视为“当前”。  
用途：保留真实交互，不把视觉升级变成静态视觉稿。

### 吸收

- 可拖动的 Archive 物件；
- 物件布局在本地持久保存；
- 没有发生拖动时，点击即可打开文件；
- 被抓取的物件升到叠层顶部，释放后通过柔和的物理反馈落回桌面；
- 点击花朵时的微反馈；
- 双语标签；
- 静态导出与 reduced-motion 降级方案。
- 珍珠石材空间、登记章式导航标记，以及跨真实折痕排版的「关于小悦」墨字，是当前用户批准的页面专属选择；可保留，但不升级为所有项目的永久规则。

### 不复制

- 系统手写字体后备栈；
- 重复出现的笔记本电脑自预览；
- 三个世界使用同一种风格；
- 通用的圆角项目网格；
- 没有证据的指标；
- 为了“高级”移除圆角、手写字标、花和物件感。

## 参考 04 — Apple 产品叙事

来源类别：Apple 当前产品页与产品发布叙事；本次没有用户上传的指定 Apple 截图。  
用途：Work 的质量标准、媒体尺度、节奏和产品中心。

### 吸收

- 一个章节只讲一个命题；
- 真实媒体拥有最大面积；
- 标题 / 媒体 / 证据之间的强层级；
- 吸附章节、遮罩揭示、媒体展开；
- 指标、条件和脚注共存；
- 短而准确的文案。
- 精致的状态连续性、阻尼、遮罩和媒体展开，可与 XIAOYUE 的圆角 Archive 共存。

### 不复制

- Apple 字体、Logo、设备页面模板；
- 精确布局、滚动曲线和摄影构图；
- 所有项目统一黑底产品页；
- 与个人项目内容无关的商业语气。

## 参考 05 — 创意操作系统 / 无限画布

来源类别：用户描述的 AI 创意操作系统 / 工作流 / 空间界面，以及当前公开的无限画布 / 节点工作流产品。  
用途：Work 中呈现 Agent、媒体、工作流和生成过程。

### 吸收

- 输入、Agent、工具、媒体、输出在同一个空间里可见；
- 视角从完整流程移动到局部证据；
- 中间产物可以被比较和回溯；
- 连接线表达真实的数据流；
- 作品自己演示自己。

### 不复制

- 任一产品的精确画布、节点、工具栏或品牌；
- 为了“科技感”制造无意义连线；
- 所有案例研究都做成无限画布；
- 没有真实流程时伪造复杂工作流。

### 素材缺口

用户提到 Spectrix，但本次没有对应截图或可确认 URL。需要精确吸收其视觉时，应发出 `MEDIA REQUEST`，请用户补充原图或链接后再归档。

## 参考 06 — 研究 / Lab 证据

来源：当前公开项目的 README、Benchmark 描述、追踪 / 评估结构。  
用途：Lab 的信息层级与真实性协议。

### 吸收

- 运行编号（run id）、数据集、基线、方法、指标、环境与日期；
- 执行追踪、工具调用、检查点与失败案例；
- 明确区分 `REPOSITORY REPORTED` 与本次 `VERIFIED`；
- 真实图表 / 表格优先于装饰性仪表盘。

### 不复制

- 论文的精确版式；
- 没有数据的图表；
- 只有成功结果；
- 把 README 声明直接改写成本次实测。

## 参考 07 — GitHub Profile 资产

来源：`hey-Chloe/hey-Chloe` 中的 `bloom.svg`、`sky.svg`、`sky-night.svg`、`garden-footer.svg` 和技术 chips。  
用途：长期身份资产、浅色 / 深色状态、季节感。

### 吸收

- 珊瑚色 `#F4795B` / 暖红色 `#E2542F`；
- 绿色 `#7FA36B` 及其夜间变体；
- 白天 / 夜间状态；
- 花园页脚中的生命感和小叙事。

### 不复制

- 把所有 SVG 原样搬到网站；
- 页面主要信息依赖超宽横幅；
- 每种技术都制作一个品牌标签；
- 让动态天气成为主内容。
