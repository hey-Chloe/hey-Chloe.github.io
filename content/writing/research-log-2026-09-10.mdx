今天完成了 SciFact 检索实验的全量查询变化分析，并准备下一项编码经验数据审计。
以下是阶段研究记录：包含真实公开数据上的独立实现与探索分析，不代表原论文完整复现、原创方法或 Agent 能力提升。

## 固定设置下的负结果

实验使用 BEIR 发布的 SciFact 数据：5,183 篇文档、全部 300 个公开 test 查询。
这个 split 对应原 SciFact 的公开 dev，不是隐藏测试集。

在相同 Unicode 分词、k1=0.9、b=0.4 下，对比将标题与正文合并计算 BM25，
以及分别计算字段统计与归一化、再以 max + 0.5 × min 聚合的独立实现。
合并字段 baseline 先与已有运行的排名文件逐字节核对一致。

| 设置 | nDCG@10 | MRR@10 | Recall@100 |
| --- | ---: | ---: | ---: |
| 合并标题与正文 | 0.661835 | 0.630537 | 0.885222 |
| 分字段计算后聚合 | 0.652560 | 0.618226 | 0.880889 |

分字段设置的平均 nDCG@10 差值为 −0.009275，没有支持预设的 +0.01 改善幅度。
探索性 query bootstrap 的 95% 区间为 [−0.026811, 0.007409]，包含零。
该区间未校正共享相关文档所产生的依赖，也没有消除多次查看公开测试数据的影响，不能据此声称确认性的显著下降或两种设置等价。

本轮同时改变了字段统计、归一化和聚合方式，无法把差异单独归因于其中一个因素。
负结果完整保留；没有继续根据这组 test 结果调整权重。

## 300 条查询发生了什么

今天对全部查询作了事后分类，没有只挑展示案例。

| 观察到的变化 | 查询数 |
| --- | ---: |
| 失去 top-10 已标注相关文档命中 | 7 |
| 新增 top-10 已标注相关文档命中 | 6 |
| 两种设置都命中，nDCG 下降 | 36 |
| 两种设置都命中，nDCG 上升 | 33 |
| 两种设置都命中，nDCG 相同 | 165 |
| 两种设置均未命中 top-10 | 53 |

仍然保留命中的查询对总体 nDCG 差值贡献约 −0.008688；新增与失去命中两类合计贡献约 −0.000587。
因此，观察到的负差值主要来自仍保留命中的查询内部的排名变化。
这是算术分解，不是失败原因的证明；原因仍为 **UNKNOWN**。
未标注文档也不能直接视为不相关。

## 下一项：编码经验数据的关系审计

已下载固定版本的 SWEContextBench 经验池、目标任务与关系表，
并在现有离线 sandbox 中验证了 PyArrow 解析环境。
Parquet footer 显示 1,100 条经验记录、376 条目标任务记录与 376 条关系记录。
这一步只确认环境与文件 schema 可读取；全量关系及时间顺序审计尚未运行。

下一项将检查关系端点能否唯一连接，以及文档所述的 PR 创建时间顺序。
PR 创建时间不等于解决方案首次公开时间；时间顺序也不自动意味着泄漏或原 benchmark 存在错误。
Agent 的技能迁移效果仍为 **UNKNOWN**。

本轮额外计量研究服务费用为 0 USD，未调用付费模型接口。
