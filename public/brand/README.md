# Chloe’s Archive wordmark

Canonical text: `Chloe’s Archive` (curly apostrophe U+2019).

The live wordmark is implemented by `components/ChloesArchiveWordmark.tsx` and the self-hosted Kaushan Script Regular 400 webfont. Use the component for branded signatures instead of recreating the lettering with a system handwriting stack.

- Main signature: stacked on Home and Archive.
- Compact signature: one line on the Archive desk and legacy Archive navigation.
- Provenance: official Google Fonts v19 Latin WOFF2, unchanged.
- License: SIL Open Font License 1.1; see `public/fonts/kaushan-script/OFL.txt` and the repository root `THIRD_PARTY_NOTICES.md`.
- Language boundary: the font is Latin/Latin Extended and must not be used for Chinese UI, navigation, or body copy.
- Reserved Font Name: do not subset, redraw, rebuild, or rename a modified derivative as `Kaushan Script` without separate authorization.
